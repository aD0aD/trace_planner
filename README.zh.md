# Trace Planner（中文使用手册）

Trace Planner 是一个在线轨迹拼接与分析工具，适合徒步、越野、拉练路线复盘。
直接在浏览器使用，无需安装、无需登录。

- 官方网站: [https://ad0ad.github.io/trace_planner/](https://ad0ad.github.io/trace_planner/)
- 支持语言: 中文 / English（页面右上角切换）
- 支持主题: 浅色 / 深色（页面右上角切换）

---

## 一、核心功能

### 1) 轨迹导入与显示
- 支持导入 `KML` / `KMZ` / `GPX`
- 支持同时导入多条轨迹
- 支持关键词跳转搜索轨迹（两步路 / 六只脚搜索）
- 地图可切换卫星图 / 地形图 / 街道图，并可叠加阴影地形

### 2) 轨迹拼接
- 可在任意导入轨迹上选择起点终点截段
- 支持反向片段（反穿）
- 支持拼接篮子排序、删除、反向后生成新轨迹

### 3) 分析能力
- 总距离、总爬升、总下降统计
- 断点分段分析（每段距离/爬升/下降）
- 实时高度图联动起终点
- 爬升算法支持原始 / 平滑 / 平滑+阈值

### 4) 标注系统
- 支持不同颜色类型（起点、终点、营地、补给、风险、普通）
- 地图点击添加标注
- 标注支持文字 + 可选图片
- 标注列表支持：定位 / 编辑 / 删除

### 5) 导出与工程
- 导出轨迹：`KML` / `GPX` / `GeoJSON`
- 导出图表：爬升下降图 `PNG`
- 工程保存：下载 `project.json` 或保存到本浏览器

---

## 二、快速上手（推荐流程）

1. 打开网站，切换到你习惯的语言和主题
2. 在“导入多条轨迹”中选择文件
3. 在“轨迹拼接工具”里截段并加入拼接篮子
4. 点“生成拼接轨迹”
5. 在“轨迹分析工具”里查看分段统计、高度图、标注
6. 导出轨迹或下载工程 JSON

---

## 三、工程保存说明（非常重要）

你有两种保存方式：

- **下载工程 JSON（推荐）**
  - 可跨设备、可备份、可分享给队友
- **保存到本浏览器**
  - 仅当前浏览器可见，清缓存或换设备会丢失

建议：每次重要编辑后，都下载一份 `project.json`。

## 六、常见问题

### Q1: 为什么导入后只看到部分轨迹？
可能是原始文件中存在多段/重复点/异常点，建议先用单条文件测试，再逐步导入。

### Q2: 为什么不同文件的爬升差异很大？
海拔采样设备和噪声不同，建议切换不同爬升算法进行对比。

### Q3: 工程加载失败怎么办？
优先检查 JSON 是否被手动编辑或损坏；尽量使用工具导出的原始 `project.json`。

## 八、领队规划更新（v3）

### 路线与数据质量

- 每条路线独立保存标注、分段、行程参数、名称、版本和用途（主线 / 备选 / 下撤）。拼接成果加入路线列表，可随时切换。
- 导入 GPX 时保留 `trkseg`，支持 `rte/rtept`；KML 保留多条线的边界；KMZ 读取其中所有 KML 与引用的内嵌图片。
- 红色虚线表示未确认连接，不代表存在可通行道路。缺口不计入已记录里程或爬升；生成及导出前会提示保留断段。
- 缺失海拔显示“未知”或“部分数据”，不自动补造海拔。平滑不跨越断段和缺失数据；阈值模式累计缓坡变化。不同采样密度和记录设备仍会影响结果。
- 轨迹坐标按 WGS84 经纬度读取，不自动转换其他坐标系统；请用已知地点检查底图与轨迹是否对齐。

### 关键点与分段

- 关键点保留真实位置，可编辑经纬度、类型、核实状态、备注、参考链接和图片。水源可靠性、下撤去向、交通和核实日期可填写在备注中。
- KML / GPX 导入的关键点使用独立身份编号，移动坐标后不会重新生成原位置的点；删除、切换路线、工程保存和撤销重做均保留该身份。旧工程中的点按原坐标匹配后自动补充编号。
- 离最近轨迹采样点超过 100 米的关键点保留在地图上，但不关联里程。稀疏轨迹也可能出现未关联点。
- 在分析页点击“地图选断点”、点击高度图，或点击关键点的“分段”，可建立分段。自动均分按已记录里程进行。
- 分段名称与行程参数按边界保存；改变边界会产生新路段，原边界的参数不会自动移到其他路段。
- 图片自动缩小到最长边 1280 像素。GPX / KML 用 Trace Planner 扩展保存关键点详情；其他导航软件通常只读取标准名称、备注、坐标，可能忽略图片和核实状态。完整交接请同时分享工程 JSON。

### 行程与路书

1. 填写路线名称、用途、版本和出发时间。
2. 设置每段平地速度、爬升速度和休息时间；也可手填该段移动用时覆盖估算。
3. 估算公式为“距离 ÷ 平地速度 + 爬升 ÷ 爬升速度”，休息另外累计。缺海拔或存在缺口时需手填用时，否则后续到达时间显示“待补用时”。
4. 填写最晚通过时间和决策备注。最晚时间按出发当天计算；多日活动可拆分每日路线，并在备注注明跨日决策时间。
5. “复制为备选路线”保留原主线。“打印路书 / 保存 PDF”生成路线示意图、剖面、行程表、关键点与备选路线目录；打印稿不含在线底图。
6. 可另导出行程 CSV；轨迹文件名包含版本和用途，便于团队核对。

### 草稿、撤销与离线

- 编辑后自动保存一个浏览器草稿；“恢复草稿”可恢复。打开其他工程会提示替换当前内容。
- 支持最近 20 次工程状态的撤销 / 重做。历史仅保留在当前页面会话；浏览器空间不足时会提示下载工程。
- 成功在线打开并完成应用缓存后，可离线再次打开应用、编辑轨迹、恢复草稿和导出文件。底图与外部图片仍依赖网络，没有预下载离线地图功能。
- 轨迹不上传。在线底图、链接导入及外部图片会访问相应第三方服务；手动添加的本地图片留在工程中。

## 九、本地 DEM 地形图

本地试用：macOS 双击项目目录里的 `start-local.command`，保持终端窗口打开，再访问 <http://127.0.0.1:8765/Trace_planner.html>。也可以在项目目录运行 `npm start`。直接双击 HTML 得到的 `file://` 页面无法使用 DEM Worker，页面会显示启动说明；此前在该页面编辑的工程可先下载 JSON，再到预览页面打开。

Worker 仅缓存最近一次裁剪的高程网格，缓存高程上限 8 MiB（现有 120 万像元限制下实际不超过约 4.8 MB），不会随操作累积。切换等高距或阴影复用该网格，无需再次读取 TIFF；改变裁剪范围、重新选择或移除 DEM 时清除旧缓存。缓存仅在当前页面会话内保留，不写入工程或草稿。

展开“本地 DEM 地形图”，可导入一份或多份 `.tif / .tiff`。当前支持北向上、单波段、WGS84 经纬度（EPSG:4326）的 GeoTIFF，高程单位为米。ASTER GDEM 请选 `_dem.tif`；`_num.tif` 是观测次数，不能作为高程图。ASTER 旧文件没有 NoData 标签时按其约定将 -9999 视为缺失。

1. 导入 GPX/KML 路线，再同时选择覆盖路线的 DEM 文件。
2. 默认裁剪“当前路线周边”，向外扩展 2 km；也可选择“当前地图视野”，或点“地图框选”后在地图点击两个对角点。
3. 等高线默认 20 m，可选 10 / 20 / 50 / 100 / 200 m，或关闭。每五条加粗一条，较长的加粗线显示海拔数字。
4. 可切换地形阴影、隐藏地形、关闭自动更新，或取消正在进行的计算。开启自动更新时，切换路线或调整参数会更新；当前视野模式在移动地图后更新。
5. “导出地形图 PNG”包含本地地形、当前路线、关键点、等高距和比例尺。地形不会修改原轨迹海拔，也不会从 DEM 自动生成道路或河流。

地形在独立 Worker 中计算：先读取文件元数据，再按裁剪范围分批读取像元窗口。输出网格最多约 120 万像元，优先使用文件内的概览层；没有概览的大范围区域可能需要扫描较多条带。超过 32 MB 的单个解压块、横跨过多解压块的裁剪会提示先缩小范围或转换为带概览的分块 GeoTIFF。读入后转换为地图使用的 Web Mercator 网格，多文件共享等高线提取；空白和 NoData 保持透明。设色色带按本次裁剪的有效高程范围生成，放大已有栅格不会增加原始 DEM 的地形精度。

工程 JSON、草稿和撤销记录仅保存地形参数、文件名及大小，不内嵌 DEM 原文件。重新打开页面、加载引用另一套 DEM 的工程或撤销文件移除后，请重新选择所需文件。DEM 不上传，应用完成缓存后可离线打开并重新选择本地文件。本地开发请通过 HTTP 服务访问，而不是直接双击 HTML。

测试默认用生成的微型 GeoTIFF 验证跨文件接缝、NoData、等高距切换、取消、导出、工程恢复和移动端。真实数据测试可选择性运行（数据不会复制进仓库）：

```sh
DEM_TEST_FILES='/path/west_dem.tif;/path/east_dem.tif' \
DEM_TEST_KML='/path/route.kml' \
DEM_TEST_OUTPUT='/path/output' \
node tests/dem-browser.test.cjs
```

真实测试输出 20 m 地形 PNG、桌面/手机截图、工程 JSON 和裁剪统计报告。工程加载后需重新选择原 DEM 文件。
